# 技能核心
以经典三层架构（接入层 / 汇聚层 / 核心层）+ 防火墙 + 出口 + DMZ 为范式，固化为一套交互式、可落地的部署工作流，最终产出两份东西：一份 Word 项目文档 + 一组逐设备配置文件（使用者照着敲命令即可部署）。

七阶段流程（核心设计）
采集设备清单 — 角色 / 品牌 / 型号 / 数量（如"思科 c2960 两台、华为 s5735 两台、USG6000 两台热备…"）。
采集互联与逻辑设计 — 每台设备的 IP、接口互联关系、VLAN、放行网段、协议、策略。
⚠️ 关键决策必须暂停询问（这是硬关卡）——路由协议 OSPF/IS-IS、防火墙热备方式、NAT 策略、是否 LACP/堆叠、AAA 认证、SNMP/BFD 监控。你没给就坚决问，绝不臆断。
AI 自定非必要项出草案 — 具体端口号、VLAN ID、IP 末位等由 AI 合理分配并列出，你回"没问题"才锁定。
可行性分析 — 主动排查 IP 冲突、路由环路、STP 根桥、脑裂、ACL 方向、厂商型号能力（如 c2960 纯二层不能跑 OSPF）等，逐条给"问题→影响→方案"，带病不进入下一步。
生成 Word 文档 — 拓扑图（ASCII 框线）+ 台账表（命名/IP/账号密码/VLAN/协议）+ 逐模块详述（比如"ACL 2000 干什么、哪台 Loopback 是 router-id、在哪为路由优选调了 cost"）。
生成逐设备配置 — 按 主机名_角色_v1.txt 命名（如 AR1_出口设备_v1.txt、FW1_边界防火墙_v1.txt），命令严格对照厂商 CLI。

# 使用
提供具体的需求文档，描述设备型号、网络拓扑、协议选择，以及路由策略、故障检测、链路聚合、虚拟化、监控维护、各种网络安全相关协议等等信息
拓扑图尽量再补充文字描述，越具体越好，如：
ISP(G0/1)--(G1/0/1)R1(G1/0/2)--(G1/0/1)DSW1......
