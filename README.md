# network-deploy — 网络项目部署技能

面向**企业网 / 园区网规划与落地部署**的 WorkBuddy 技能。输入一段需求描述（设备、规模、用途），技能会通过**强交互式对话**逐步澄清需求、确认关键决策，最终交付：

1. **一份 Word 项目设计文档**：拓扑图 + 设备台账表 + 关键决策记录 + 逐模块文字详述；
2. **一组逐设备配置文件**：按 `主机名_角色_v1.txt` 命名，**照着敲命令即可部署**；
3. **一份部署验收清单**：导入 eve-ng / 真机后逐项验证（连通性、OSPF 邻居、VRRP、DHCP、NAT…）。

> 技能遵循"先问清、再产出"的纪律：规划阶段的每个关键决策（路由协议、NAT、防火墙 HA、链路聚合、DHCP 策略等）都会列出选项**等你确认**，不会擅自替你定方案；部署阶段遇到报错，也会先收集现场信息再给更正方案，直到项目验收通过。

## 一、它能做什么

| 能力 | 说明 |
|------|------|
| 需求澄清 | 自动询问设备清单、网络规模、互联与逻辑设计（IP/VLAN/协议/策略） |
| 关键决策确认 | 路由协议、NAT、HA、链路聚合、AAA、监控、DHCP、二层安全、QoS、IPv6、WLAN 等逐项列选项确认 |
| 自动划址 | `ip_planner.py` 按各 VLAN 终端数自动 VLSM 划址（网段/网关/互联 /30/loopback/DHCP 池） |
| 方案校验 | `check_project.py` 程序化检查 IP 冲突、端口占用、跨厂商聚合、型号能力等 |
| 拓扑绘图 | `gen_topo.py` 从项目模型自动生成**可视化拓扑图**（分层布局、形状/颜色区分、链路接口与网段标注、图例） |
| 文档生成 | `gen_docx.py` 一键生成 Word 文档（含可视化拓扑图、目录、页码、自动规划表、敏感信息脱敏） |
| 配置生成 | `gen_configs.py` 从项目模型生成三厂商配置骨架（注释符天然正确、自动带保存命令） |
| 命令查证 | 三方交叉验证（AI 记忆 + 网络搜索 + cmds.md 参考），确保 CLI 语法准确 |
| 部署排障 | 阶段 8 交互式纠错：收集报错现场 → 定位根因 → 给更正方案 → 确认闭环 |
| 安全加固 | 可选增强轮次：全网安全加固基线（SSH v2、管理隔离、NTP、控制平面保护） |

**支持的厂商**：思科（IOS/IOS-XE）、华为（VRP）、华三（Comware）、锐捷（RGOS）、山石（StoneOS）、深信服等 —— 内置速查参考覆盖前三家，其余按 AI 记忆 + 联网查证。

## 二、使用示例

### 示例 1：完整项目（推荐，演示完整流程）

**你只需要说：**

> 帮我规划并部署一个三层架构的园区网络。规模：两栋楼、约 500 个终端，有无线覆盖需求。设备我大概想用：华为 S5735 两台做核心（热备）、华三 MSR 两台做出口、华为 USG6000 防火墙两台做 HRP 热备，接入层用思科 C2960 若干。需要划分办公、语音、无线、DMZ 几个网段，办公区要能出公网。预算 100 万以内，要满足等保二级。

**技能会依次与你确认：**

1. **阶段 0 需求规模**：楼宇/终端数/带宽/预算/合规（你已提供大部分，只补少量缺项）；
2. **阶段 1 设备清单**：汇总成表格回显 —— *"以下设备清单是否正确？"*；
3. **阶段 2 互联与逻辑**：询问 IP 规划、VLAN、接口互联、路由协议等，你心里有数的给，没有的留空；
4. **阶段 3 关键决策**（逐项列选项等你选）：
   - *"路由协议：A. OSPF（推荐） B. IS-IS C. 静态为主"*
   - *"NAT 策略：A. 出方向 PAT（推荐） B. 仅 DMZ 静态映射 C. 暂不需要"*
   - *"无线接入：A. AC+AP（推荐） B. 暂不需要"* …（共 11 项左右）
5. **阶段 4 完整草案**：拓扑草图 + 台账初稿 + 划址表，等你确认"没问题"；
6. **阶段 5 可行性分析**：跑 `check_project.py` 出校验报告，风险处理方案逐条确认；
7. **阶段 6/7 产出**：生成 `项目设计文档.docx` 与 `配置/` 下逐台设备的 `主机名_角色_v1.txt`；
8. **阶段 7.5 验收**：给你验收清单，导入 eve-ng/真机逐项验证；
9. **阶段 8 排障**：部署中报错贴给我，先问清现场再给更正方案，直到全部 ✅。

### 示例 2：快速起步（已有明确设计）

## 三、需要你提供的信息

**给得越全，确认轮数越少。** 建议按下面清单尽量一次性给出：

| 信息类别 | 示例 |
|----------|------|
| 项目背景/目标 | "某公司园区网，供 500 人办公 + 无线覆盖" |
| 网络规模 | "两栋楼、10 间机房、约 500 终端、出口 1G" |
| 设备清单 | "华为 S5735×2（核心，热备）、华三 MSR×2（出口）、思科 C2960×5（接入）" |
| 品牌/型号/数量 | 每台设备的品牌型号与台数、主备/堆叠关系 |
| IP 规划 | 管理网段、业务网段、互联网段（没有则技能代划，但会列草案给你审） |
| VLAN 规划 | 需要哪些 VLAN、ID/名称/归属（没有则技能代分配） |
| 协议/策略偏好 | 路由协议、是否 NAT、是否要 802.1x、是否要无线等 |
| 特殊要求 | 等保合规、QoS、IPv6、访客隔离、预算上限 |
| 冗余要求 | 哪些设备要热备/堆叠（HRP、VRRP、iStack/IRF） |

> 不必一次给全 —— 技能会**主动追问**缺项。你只需要回答"是/否/选 A/B/C"即可。

## 六、部署后如何验收

1. 将 `配置/` 下各文件逐台粘贴到 eve-ng / 真机；
2. 按技能给出的验收清单逐项验证（连通性、OSPF 邻居 Full、VRRP 主备、DHCP 下发、NAT 转换…）；
3. 使用 `references/verify.md` 中的**三厂商一键巡检命令集**整段粘贴，快速核对；
4. 遇到报错直接把**设备回显原文**贴给技能（哪台设备、哪个视图、完整报错行），技能会先问清现场再给更正方案，直到全部 ✅ 验收通过。

## 七、注意事项

- **Word 文档生成依赖 `python-docx`，拓扑图生成依赖 `matplotlib`**，技能会自动在隔离的虚拟环境中安装，不污染全局 Python；
- 文档与配置含账号密码等敏感信息：对外交付请让技能使用 `--mask-secrets` 脱敏，明文凭据单独加密保存；
- 配置命令采用"AI 记忆 + 网络搜索 + 参考库"三方交叉验证，**网络不可用时以 AI 记忆为准并会明确告知你哪条命令有冲突风险**，真机部署前建议在 eve-ng 模拟器先行核对；
- 本项目为强交互式流程：**技能提问时请尽量逐项回答**，说"你决定"只会让技能把推荐项列给你确认，不会跳过决策关卡。
