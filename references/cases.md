# 标准方案案例库（cases）

阶段 1 用户描述需求后，先匹配最接近的模板，再按实际设备/规模调整，可显著减少确认轮数。每个模板给出：适用场景、默认拓扑、VLAN/协议默认决策、注意事项。**模板只作默认建议，关键决策仍须阶段 3 逐项与用户确认。**

---

## 案例 A · 小型办公网（1 栋楼，≤100 终端）

**适用**：小微企业/单层办公室，预算有限，无独立防火墙或仅一台出口网关。

**默认拓扑**：
```
[ ISP ] ── [ AR 出口路由（NAT+DHCP）] ── [ DSW 三层核心（VLAN网关）]
                                          │
                                   [ ASW 二层接入 ] ── PC
```

**默认决策**：
- VLAN：MGMT 10、办公 20、访客 30（可选）；
- 路由：静态路由为主（无 OSPF 复杂度）；
- NAT：出口 PAT（默认推荐）；DHCP 由 AR 承担；
- 冗余：单机（预算有限，无 HA）；STP RSTP 自动。

**注意事项**：规模小、不跑 OSPF 时，核心只需静态 + 直连路由；网关终结在 DSW 或 AR 均可。

## 案例 B · 校园网（多栋楼，500–2000 终端）

**适用**：学校/园区多栋楼，需要汇聚层、无线覆盖、多业务隔离。

**默认拓扑**：
```
[ ISP1 ] [ ISP2 ]
    └──────┬──────┘
      [ AR1/AR2 出口（双出口主备）]
           │
      [ FW1/FW2 防火墙 HRP 热备 ]
           │
    [ DSW1/DSW2 核心 VRRP + MST ]──[ DMZ 服务器区 ]
           │
    ┌──────┴──────┐
  [ AGW 汇聚 ]  [ AGW 汇聚 ]
     │   │          │   │
  [ASW][ASW]    [ASW][ASW]  + 无线 AC/AP
```

**默认决策**：
- VLAN：MGMT 10、办公 20、教学 30、语音 40、无线 50、访客 60、DMZ 70；
- 路由：OSPF area 0（核心+汇聚）、area 1/2（接入侧可选）；
- 冗余：DSW 双机 VRRP（奇数 VLAN 主 DSW1、偶数主 DSW2）+ MST 双根；
- NAT：出口 PAT；DMZ 静态映射；
- 无线：AC+AP，无线 VLAN 走 802.1x（员工）与 WPA2-PSK（访客隔离）；
- QoS：语音 VLAN 打 DSCP EF。

**注意事项**：多栋楼需规划汇聚层与核心互联 /30；访客 VLAN 建议勾选"隔离+限速"。

## 案例 C · 双出口园区（业务分流/合规）

**适用**：两个运营商出口、需要业务分流（财务/研发走专线）、或主备出口容灾。

**默认拓扑**：
```
[ ISP1 电信 ]      [ ISP2 联通 ]
     │                  │
  [ AR1 ]            [ AR2 ]
     └────────┬─────────┘
        [ FW（可选）/ DSW 核心 ]
```

**默认决策**：
- 出口：PBR 或 route-map 按业务分流（财务 VLAN 走 R2、普通走 R1）；
- 冗余：BFD 检测 + 静态路由联动（track/NQA），或跑 BGP（运营商需宣告公网段时）；
- NAT：各出口独立 PAT；双出口链路备援；
- 若启用 BGP：需公网 AS 号、对端 AS、prefix-list 过滤。

**注意事项**：双出口策略是**必须显式确认**的决策项（哪条链路承载什么业务、故障时如何切换）；不跑 BGP 时推荐"BFD+track+静态默认路由"实现自动切换。

## 案例 D · 数据中心（三层到接入 / 大二层）

**适用**：服务器区、虚拟化集群，要求低时延、高带宽、横向流量。

**默认拓扑**：
```
      [ 核心路由器 ]
           │
    [ Spine 核心交换机 ]──[ Leaf 接入交换机 ]──[ 服务器/存储 ]
```

**默认决策**：
- 网络模型：Spine-Leaf（三层到接入）或 MLAG/M-LAG 双活接入；
- 虚拟化：VLAN 直通或 VXLAN（跨机房大二层）；
- 冗余：Leaf 双上联 MLAG，跨厂商禁止聚合（用静态 Trunk）；
- QoS：存储/业务流量优先；
- 监控：BFD + 全端口镜像/流采样。

**注意事项**：数据中心特性（VXLAN、EVPN、M-LAG）通常需 License，且 CE 系列命令与普通 VRP 差异大，**必须 Web 查证对应版本命令**。

## 模板匹配建议

| 用户描述 | 匹配模板 |
|----------|----------|
| "小公司/办公室，几十台电脑" | A 小型办公网 |
| "学校/园区，好几栋楼，有无线" | B 校园网 |
| "两个出口/两条宽带/业务分流" | C 双出口园区 |
| "机房/服务器/虚拟化/存储" | D 数据中心 |
| 混合需求 | 取主模板 + 其他模板的补充项（如 B+无线、C+PBR） |

匹配到模板后，在阶段 1/2 与用户核对设备清单与规模是否符合模板假设，再走阶段 3 确认关键决策。
