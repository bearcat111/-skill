# 三层架构拓扑范例（ASCII，辅助参考）

以下为可在聊天中快速浏览的 ASCII 拓扑（**辅助用途**）。正式交付请优先用 `scripts/gen_topo.py` 从项目模型生成**可视化拓扑图 PNG**（角色分层布局、形状/颜色区分、链路标注接口网段、图例），再嵌入 Word 文档；ASCII 用于草案阶段快速回显与结构示意。按实际设备数量增删节点，用 `───` 表示链路、用方括号表示设备、括号内标注互联接口。

## 范例 A · 标准三层 + 防火墙热备 + DMZ

```
                          [ 互联网 / ISP ]
                                │
                   ┌────────────┴────────────┐
                GE0/0/0                   GE0/0/0
              [ AR1 出口路由 ]          [ AR2 出口路由 ]   ← 双出口主备
                   │  GE0/0/1              │  GE0/0/1
                   └──────────┬────────────┘
                              │  GE1/0/1 (互联 /30)
                   ┌──────────┴────────────┐
                GE1/0/1                  GE1/0/1
           [ FW1 边界防火墙 ]       [ FW2 边界防火墙 ]    ← HRP 热备
              (Trust)│(DMZ)          (Trust)│(DMZ)
                   │                        │
         ┌─────────┴──────────┐            │  DMZ 链路
         │   GE0/0/1           │            │
   [ DSW1 三层核心 ]──堆叠──[ DSW2 三层核心 ]   │
         │  GE0/0/2     │  GE0/0/2           │
         │              │                    │
   ┌─────┴─────┐  ┌─────┴─────┐        [ Web 服务器 ]
   │ ASW1 二层  │  │ ASW2 二层  │            │
   │ (接入)     │  │ (接入)     │            │
   └────────────┘  └────────────┘
        │ 用户PC          │ 用户PC
```

说明：
- 接入层（ASW）二层交换，上联到核心层（DSW）三层交换；
- 核心层双机堆叠/或 VRRP，下联接入、上联防火墙 Trust 域；
- 防火墙双机 HRP 热备，Trust 接内网、DMZ 接服务器、Untrust 接出口；
- 出口路由器双机，互联做主备或负载，上联 ISP。

## 范例 B · 带汇聚层（接入—汇聚—核心）

```
   [ 用户区 ]──[ ASW 二层接入 ]──┐
                                 ├──[ AGW 三层汇聚 ]──[ DSW 三层核心 ]──[ FW ]──[ AR ]── ISP
   [ 用户区 ]──[ ASW 二层接入 ]──┘
```
（汇聚层用于大型园区，做 VLAN 网关终结与路由汇聚；中小网络可合并汇聚与核心。）

## 范例 C · 纯交换园区（无防火墙，路由在出口）

```
                       [ ISP1 ]        [ ISP2 ]
                          │               │
                   GE0/0/0           GE0/0/0
              [ R1 出口路由 ]      [ R2 出口路由 ]   ← 双出口主备(思科/华三)
                   │  GE0/0/1          │  GE0/0/1
                   └────────┬───────────┘
                            │ 互联 /30
              ┌─────────────┴─────────────┐
           GE1/0/1                     GE1/0/1
      [ DSW1 三层核心 ]══LACP══[ DSW2 三层核心 ]   ← VRRP网关 + MST根
           │  GE0/0/2         │  GE0/0/2
      ┌─────┴─────┐      ┌─────┴─────┐
 [ ASW1 二层 ]  [ ASW2 二层 ]    [ ASW3 二层 ]
      PC1,2          PC3,4          PC5,6
    (安全)        (802.1x)        (安全)
```

说明：
- 无独立防火墙，安全策略由三层交换机的 ACL + 出口路由器的 NAT/ACL 承担；
- 出口路由器做 DHCP 服务器 + NAT（若需出公网），三层交换机做各 VLAN 网关与 VRRP；
- 接入层双链上联两台 DSW，MSTP 防环；此结构对应"交换特性为主"的园区实验（如实验三）。

## 画图标尺建议

- 设备：`[ 主机名 角色 ]`
- 链路：`───` 普通，`═══` 聚合/堆叠，`···` 管理/带外
- 接口标注写在链路两端：`GE0/0/1`
- 网段标注写在链路中间：`/30 10.0.0.0/30`
- DMZ、Trust、Untrust 等安全域用括号标在防火墙上联/下联处。
